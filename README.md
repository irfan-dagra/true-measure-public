# true-measure-public

Public hosting for True Measure's privacy policy and app configuration.

Served via GitHub Pages at https://truemeasuregame.com/.

Contents:
- `privacy/` — privacy policy (published separately after legal review; not yet present)
- `app-config.json` — versioned remote configuration for the True Measure app
  (analytics enablement flag, privacy policy URL)

This repository contains no game code, no credentials, and no secrets.
The game's private repository (irfan-dagra/amanah) is separate and unaffected.
